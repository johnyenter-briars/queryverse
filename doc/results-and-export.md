# Results and Export

QueryVerse presents query output in a virtualized results grid built for large result sets and quick inspection.

<SCREENSHOT / GIF HERE>

## Supported Workflows

- Render result sets in a virtualized grid.
- Keep a visible row number column.
- Show stronger grid-style row and cell separators.
- Double-click a cell to copy its value.
- Show toast notifications for copy and related frontend actions.
- Surface query execution errors inline in the results area.
- Copy rows or values into downstream tools as needed.

## Notes

- The grid is optimized for readability and large-result scrolling rather than spreadsheet-style editing.
- Copy flows are intentionally lightweight so common inspection work takes one gesture instead of extra menus.

## Why This Matters

Execution speed is only useful if result handling is fast too. The results area is tuned for inspection-first workflows.
