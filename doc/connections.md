# Connections and Project Organization

QueryVerse keeps Dataverse connections in a tree with folders, colors, and context-menu management.

<SCREENSHOT / GIF HERE>

## Supported Workflows

- Create connection profiles.
- Edit connection profiles.
- Delete connection profiles.
- Organize connections into folders.
- Create subfolders.
- Edit folders.
- Delete folders recursively, including nested folders and their connections.
- Reorder connections up and down within a sibling group.
- Reorder folders up and down within a sibling group.
- Highlight the connection or folder currently being edited.

## Important Behavior

- Clicking a connection in the tree opens a new connected query tab.
- It does not switch the connection for existing tabs.
- Right-click menus are the primary place for connection and folder management actions.

## Why This Matters

The connection tree is meant to behave more like a project navigator than a single active-environment picker.
