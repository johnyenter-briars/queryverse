# QueryVerse 

- Perform SQL queries against [Microsoft Dataverse](https://learn.microsoft.com/en-us/power-apps/maker/data-platform/data-platform-intro) ⚡blazingly⚡fast!


## High-Level Objectives 
- Drop-in replacement for SQL client 
    - Read / update
    - SQL to fetch engine
    - Paging
    - JSON to entity conversion
    - TDS optimization
- Convert to fetch XML
- Save SQL files
- Save multiple connections
- Tabs 
    - Each tab is different connection
- Results window
    - Copy to json
    - New window as json
